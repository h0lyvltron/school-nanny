Import

Adds new written plans from a YAML or CSV file. It never merges into a plan you already have.

File format

Same fields either way. subject is a name or slug, like math or Language Arts. Lesson order in the file becomes the sequence. Optional page_start / page_end mark PDF pages. PDFs are attached on the plan page after.

plans:
  - name: 3rd grade Math
    subject: math
    items:
      - week: 1
        title: Place value
        minutes: 40
        page_start: 12
        page_end: 15

CSV header: plan,subject,week,title,minutes,notes,page_start,page_end
